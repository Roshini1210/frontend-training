
# Frontend Training 🚀

A hands-on journey through JavaScript, React, and frontend development, focusing on independent coding, problem-solving, and building real-world applications.

## Learning Roadmap

### Day 01 — JavaScript Arrays & Data Processing
- Array fundamentals and array manipulation
- Mutating and non-mutating array methods
- `map()`, `filter()`, and `reduce()`
- Method chaining
- Sum, average, maximum, and minimum calculations
- Processing arrays of objects
- Product filtering, transformations, and calculations

### Day 02 — JavaScript ES6+ Fundamentals
- Destructuring arrays and objects
- Nested destructuring and default values
- Spread and rest operators
- Array and object copying
- Shallow vs deep copying
- Function declarations and expressions
- Arrow functions
- Parameters, arguments, and return values
- Default parameters
- Callbacks
- Closures
- Shopping cart implementation

### Day 03 — Asynchronous JavaScript
- Promises
- `async` and `await`
- Error handling
- Fetch API
- Working with API data

### Day 04 — React Fundamentals
- Components
- JSX
- Props
- State
- Rendering
- Todo application

### Day 05 — Forms & Component Communication
- Controlled components
- Form handling
- Component communication
- Notes application

### Day 06 — React Hooks
- `useState`
- `useEffect`
- Custom hooks
- Habit Tracker v2

### Day 07 — CSS & Responsive Design
- Flexbox
- CSS Grid
- Responsive layouts
- Dashboard UI

### Day 08 — Routing & API Integration
- React Router
- API integration
- Weather application

### Day 09 — Independent Development
- Task management UI
- Independent implementation
- Code organization
- Debugging and refactoring

### Day 10 — Final Project
- Product implementation
- Code review
- Architecture improvements
- Independent development assessment

## Learning Philosophy

- Understand concepts before implementation.
- Write code independently.
- Avoid unnecessary AI dependency.
- Test edge cases.
- Refactor and improve code.
- Explain every line of code written.
